Enabling

Capabilities and initiatives that help other teams adopt new technologies, practices, or architectural approaches.

Team Topology

Team type: Enabling

Primary interaction: Facilitation

Typical engagement: Temporary and capability-building

Purpose

Enabling teams should increase the capability of stream-aligned teams rather than becoming permanent dependencies.

Examples:

enabling/
├── migration/
├── performance/
├── testing/
└── architecture/

Interaction Model

Typical lifecycle:

Stream Team
     │
     │ capability gap
     ▼
Enabling Team
     │
     │ collaboration / facilitation
     ▼
Stream Team
     │
     │ capability transferred
     ▼
Stream Team operates independently

What Enabling Teams Should Not Become

An enabling team should not become a permanent implementation bottleneck.

Avoid:

Commerce
    │
    │ every deployment
    ▼
Enabling
    │
    ▼
Production


Prefer:

Enabling
    │
    │ teaches / facilitates
    ▼
Commerce
    │
    ▼
Production
